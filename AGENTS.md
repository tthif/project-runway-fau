# Project Runway FAU

Este é o repositório oficial do Project Runway FAU, um reality de moda com uma temporada em andamento.

## Regras do projeto

- Preserve os dados, as regras da competição, a integração com o Firebase e a identidade visual do projeto.
- Priorize a experiência em dispositivos móveis ao implementar e validar mudanças na interface.
- Antes de editar, consulte a versão mais recente da branch `main` no GitHub e compare-a com o checkout local.
- Execute os testes pertinentes e apresente as alterações realizadas e os resultados dos testes.
- Durante os testes, não altere dados reais da competição. Use dados fictícios ou um ambiente de teste isolado quando a validação exigir gravações.
- Não faça push, merge ou publicação sem autorização expressa do usuário, dada com `UPA`.
